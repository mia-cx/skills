# Search content and AI visibility

## Choose the answer worth publishing

Use product facts, customer questions, support records, and available Search Console queries to identify audience needs. Inspect current search results for the target market to understand intent and useful formats. If live results or keyword tools are unavailable, label query choices as hypotheses rather than measured demand.

Group queries that need the same answer. Map each group to an existing page before proposing a new URL. Prioritize a clear audience need, product fit, and a useful next action. Search volume alone is insufficient.

For each proposed page or substantial update, record its target audience and intent, destination URL, distinctive evidence, internal links, and visitor action. Choose the format from the task: a comparison, pricing explanation, migration guide, integration example, or tutorial. Use consistent criteria and verified facts when comparing products.

## Improve the page

- Answer the main question early. Add firsthand tests, worked examples, original research, or evidence missing from existing results. Preserve observations and calculations so claims remain checkable.
- Refresh inaccurate prices, screenshots, steps, and product limits. Merge competing pages only when they serve the same intent; plan equivalent redirects and update internal links.
- Link from relevant existing pages using descriptive anchors. Connect detailed answers to broader guides and relevant product pages. Avoid mechanical keyword repetition or site-wide link dumps.
- Credit actual authors and relevant experience when appropriate. Request missing facts instead of inventing bios, testimonials, credentials, or research. Improve vague prose by adding substance.
- For programmatic content, require distinct user value and verified facts per page. Review a small representative batch before expanding. Do not generate near-identical location or keyword pages to capture rankings.

Use existing editorial and UI copy conventions. Preserve the product's terminology and supported capabilities.

## AI search visibility

Apply the provider's documented crawl and snippet controls. Preserve deliberate training and retrieval policies; different crawlers serve different purposes. Google AI Overviews and AI Mode use existing SEO fundamentals and require no special AI schema or text file. Add `llms.txt` only for an identified consumer or explicit request, with no ranking claim.

For a visibility audit, save a repeatable set of real audience questions. Record provider, model when exposed, date, locale, exact prompt, and returned source URLs. Separate brand mentions, citations, referrals, and conversions. Read the cited pages to identify evidence gaps. A single answer is a noisy observation, not a ranking or proof of causation.

Recheck comparable questions and search metrics after changes have had time to be discovered. Keep the same market and device segments when comparing organic traffic. Where available, report qualified visits and conversions alongside impressions, clicks, and CTR. Distinguish correlation from demonstrated effects.
