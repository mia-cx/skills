# SEO

Improve discovery by the people the site serves. Prioritize useful visits and conversions over rankings, backlink counts, or AI mentions alone.

## Establish the job

Read the project's direction, existing SEO implementation, and available search data. Establish the target domain, audience, market, intended public pages, and desired visitor action. Infer these from the project; ask only for missing information that changes the work.

Match the request's scope. An audit produces findings; a fix request includes implementation and verification. A content request does not require a full technical audit. With no Search Console or analytics access, continue using public pages and source code. Mark unavailable measurements as unknown.

Choose the relevant references:

- For crawling, indexing, metadata, structured data, or page performance, read [technical.md](references/technical.md).
- For keywords, page planning, content updates, or AI search visibility, read [content.md](references/content.md).
- For backlinks, mentions, journalist requests, or outreach, read [links.md](references/links.md).

## Work from evidence

1. Record the baseline. Identify inspected URLs, data source, date range, and relevant device or market segments. Separate observed defects from hypotheses. Compare equivalent periods and account for seasonality when investigating traffic loss.
2. Find the constraint. Distinguish discovery, crawling, indexing, relevance, click-through, and conversion problems. A crawlable page is not necessarily indexed; an indexed page is not necessarily competitive.
3. Choose the smallest useful intervention. For broad requests, fix unintended access or indexing blockers before expanding content. Rank remaining work by audience value, evidence, expected impact, and effort; a technical issue on a page that answers a buying question outranks site-wide warnings. Each action needs an affected URL, the source file or template that produces it, a reason, and a verification method.
4. Complete authorized work and verify its result. Report what changed, what the checks establish, and anything still dependent on external access or recrawling. Name each check the user must confirm in Search Console themselves. Technical checks cannot establish future ranking gains.

For an audit, lead with the highest-impact findings. Give evidence, the proposed fix, and a success check for each. State coverage and limitations; sampled templates do not establish site-wide coverage. Reuse existing project tracking when follow-up is needed.

## Boundaries

Preserve intentional privacy, staging restrictions, and crawler policies. Research and draft outreach within the requested task. Sending messages, submitting listings, publishing externally, deploying, or changing account settings requires authorization for that action.

Verify time-sensitive eligibility and search-engine claims against current primary documentation, because SEO advice goes stale faster than model training data. Treat SEO blogs and social posts as leads, not proof. Never invent search volume, rankings, customer results, authorship, citations, or backlink performance. Promise no indexing, ranking, or AI inclusion by a deadline.
